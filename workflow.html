Image-to-3D Multi-Angle Generation Pipeline

Technical Workflow & System Documentation | Environment: Windows / E: Drive

1. Image Ingestion & Background Stripping (BiRefNet)

  • Precision Synchronization: Configured to float32 to prevent Swin backbone convolution precision mismatch errors.
  • Orientation Normalization: Employs ImageOps.exif_transpose to resolve EXIF camera metadata rotation prior to execution.
  • Format Ingestion: Supports .heic (via pillow-heif), PNG, JPG, WebP, and TIFF, outputting a transparent RGBA cutout.

2. Multi-View Synthesis (Zero123++)

  • Local Module Decoupling: Model repository cloned directly to zero123plus_repo with dynamic sys.path discovery to bypass broken remote code loading on Windows.
  • Diffusion Conditioning: Composites cutout over a clean white background, then executes 28 Euler Ancestral denoising steps.
  • Output Slicing: Produces a 3x2 composite grid containing 6 standard camera angles and exports them as individual files.

4. Production Layer Roadmap

  • Secondary Matting: Automatically run BiRefNet on all 6 output angles to generate clean transparent assets.
  • FastAPI Layer: Expose an asynchronous POST /generate endpoint with background task scheduling via Celery + Redis.
  • CUDA Execution: Align PyTorch with the CUDA runtime to bring inference times down to ~15 seconds.
